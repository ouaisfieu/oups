# Oups. — Chronique critique de la crise politique belge

Site statique (HTML pur) publié sur https://ouaisfieu.github.io/oups/

## Déploiement
1. Copier le contenu de ce dossier à la racine du dépôt `oups`.
2. GitHub → Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
3. Soumettre `https://ouaisfieu.github.io/oups/sitemap.xml` dans Google Search Console et Bing Webmaster Tools.

Tous les liens internes sont en `/oups/…` : le site doit rester servi sous ce chemin.
